## 🍳 Featured Project – Sizzle Share

### **Sizzle Share — Recipe Sharing Platform**  
**Role:** Backend Developer  
**Tech Stack:** Node.js · Express.js · MongoDB

Sizzle Share is a full-featured **recipe sharing platform** that allows users to create, browse, and manage their favorite recipes.  
I developed the **entire backend architecture**, focusing on:

- Building RESTful APIs for recipe CRUD operations  
- Designing a clean and efficient MongoDB schema  
- Implementing secure user authentication and validation  
- Ensuring high performance and smooth communication between client and server  

The system is built to be **scalable, maintainable, and easy to extend**, making it suitable for real-world usage and future expansion.
